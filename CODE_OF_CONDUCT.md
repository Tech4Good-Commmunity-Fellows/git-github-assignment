# Code of Conduct

## Our Pledge

We are committed to providing a welcoming workshop environment where every participant can learn, ask questions, and contribute without fear of disrespect or exclusion.

## Expected Behavior

Participants are expected to:

- Treat others with respect and professionalism
- Give feedback that is constructive and specific
- Assume good intent during collaboration
- Help create a supportive learning environment
- Keep workshop communication focused on the work

## Unacceptable Behavior

The following behaviors are not acceptable in this workshop:

- Harassment, intimidation, or exclusion
- Dismissive or insulting review comments
- Disruptive behavior that blocks collaboration
- Sharing private information without permission
- Any conduct that makes another participant feel unsafe or unwelcome

## Code Review Standards

Code reviews should be respectful, specific, and focused on the contribution.

- Comment on the change, not the person
- Ask clarifying questions when needed
- Suggest improvements with clear reasoning
- Acknowledge good work when it is done well

## Reporting Concerns

If you experience or witness behavior that conflicts with this code of conduct, notify a facilitator as soon as possible.

## Scope

This code of conduct applies to all workshop activity, including pull requests, reviews, comments, and in-person or virtual discussion related to the repository.
