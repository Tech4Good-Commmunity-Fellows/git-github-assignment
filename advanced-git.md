# Advanced Git Commands

## git stash

Purpose:
Temporarily saves uncommitted changes.

Syntax:
git stash

Example:
git stash

When to use:
When switching branches without committing work.

---

## git cherry-pick

Purpose:
Copy a commit from another branch.

Syntax:
git cherry-pick <commit-id>

Example:
git cherry-pick a1b2c3d

When to use:
When only one commit is needed from another branch.

---

## git reflog

Purpose:
Shows every movement of HEAD.

Syntax:
git reflog

Example:
git reflog

When to use:
Recover commits after an accidental reset.
